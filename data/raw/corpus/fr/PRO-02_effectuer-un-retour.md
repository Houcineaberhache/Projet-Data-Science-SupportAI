# Procédure — Effectuer un retour

**Public :** client · **Durée estimée :** 10 minutes de préparation

## 1. Avant de commencer

Vérifier les trois points suivants :

1. La commande date de **moins de 14 jours** calendaires (POL-01).
2. Le produit est complet et dans son emballage d'origine.
3. Le produit n'appartient pas à une catégorie exclue du retour de convenance.

## 2. Ouvrir la demande

**Option A — Espace client**
1. Se connecter à novashop.ma.
2. Aller dans « Mes commandes ».
3. Cliquer sur « Demander un retour ».
4. Sélectionner les articles et le motif.
5. Valider la demande.

**Option B — Par courriel**
Envoyer un message à `retours@novashop.ma` avec le numéro de commande, l'article concerné et le motif.

**Option C — En boutique**
Se présenter à l'accueil avec la facture ou le numéro de commande.

## 3. Motifs de retour acceptés

| Code | Motif | Frais |
| --- | --- | --- |
| `R01` | Changement d'avis | 39 MAD |
| `R02` | Produit défectueux | Gratuit |
| `R03` | Produit erroné | Gratuit |
| `R04` | Produit endommagé à la livraison | Gratuit — traité selon POL-09 |
| `R05` | Article manquant | Gratuit |
| `R06` | Non conforme à la description | Gratuit |

## 4. Recevoir le bon de retour

Le support vérifie l'éligibilité et génère un bon de retour `RET-XXXXXX` sous **24 heures ouvrées**. Ce bon contient :

- le numéro de retour ;
- l'adresse de dépôt ou le point relais ;
- les instructions d'emballage ;
- l'étiquette prépayée, si le retour est gratuit.

## 5. Préparer le colis

1. Retirer les données personnelles de l'appareil et restaurer les paramètres d'usine.
2. Placer l'appareil, les accessoires et la notice dans la boîte d'origine.
3. Insérer le bon de retour imprimé ou le code de retour.
4. Fermer solidement le colis et apposer l'étiquette.

NovaShop décline toute responsabilité en cas de perte de données. La sauvegarde préalable est à la charge du client.

## 6. Déposer le colis

- **Point relais :** remise contre récépissé, sous 5 jours ouvrés après émission du bon (définition : POL-03, section 9).
- **Boutique :** remise à l'accueil, avec vérification visuelle.
- **Enlèvement à domicile :** disponible dans les zones A et B, sur rendez-vous.

## 7. Contrôle qualité

À réception, le service contrôle :

- la conformité du numéro de série ;
- l'état général et l'absence de dommage ;
- la présence de tous les accessoires ;
- l'absence de données personnelles résiduelles.

Le contrôle prend **48 heures**. Le client est informé du résultat par courriel.

## 8. Après le contrôle

| Résultat | Suite |
| --- | --- |
| Conforme | Remboursement ou échange déclenché (POL-02) |
| Conforme avec réserve | Remboursement partiel après accord du client |
| Non conforme | Retour refusé, produit réexpédié au client |

## 9. Délais récapitulatifs

| Étape | Délai |
| --- | --- |
| Validation de la demande | 24 h ouvrées |
| Transport retour | 2 à 5 jours ouvrés |
| Contrôle qualité | 48 h |
| Remboursement | 2 jours ouvrés |
| Crédit bancaire | 3 à 7 jours ouvrés |

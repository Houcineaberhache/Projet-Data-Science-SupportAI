# Promotions, codes promo et programme de fidélité

**Version :** 1.0 · **Entrée en vigueur :** 1er septembre 2026

## 1. Types d'offres

NovaShop propose quatre familles d'offres :

1. **Réductions permanentes** : prix barré, lots et bundles.
2. **Codes promotionnels** : réduction en pourcentage ou en montant fixe.
3. **Ventes événementielles** : soldes, Black Friday, rentrée, fêtes.
4. **Programme de fidélité NovaPoints**.

## 2. Règles générales des codes promo

- Un seul code par commande.
- Les codes ne sont pas cumulables entre eux.
- Un code ne s'applique pas aux cartes cadeaux ni aux produits signalés « prix imbattable ».
- Chaque code possède une date de validité, un montant minimum d'achat et parfois une catégorie éligible.
- Les codes sont sensibles à la casse et ne comportent pas d'espaces.

## 3. Exemples de codes

| Code | Avantage | Conditions | Validité |
| --- | --- | --- | --- |
| `BIENVENUE10` | -10 % | Première commande, minimum 300 MAD | Permanente |
| `LIVRAISON0` | Livraison offerte | Minimum 400 MAD | 31/12/2026 |
| `AUDIO50` | -50 MAD | Catégorie Audio, minimum 600 MAD | 30/11/2026 |
| `RENTREE200` | -200 MAD | Ordinateurs portables, minimum 3 000 MAD | 30/09/2026 |

## 4. Code refusé

Un code peut être refusé pour les motifs suivants :

- code expiré ou inexistant ;
- panier inférieur au minimum requis ;
- produit non éligible ;
- code déjà utilisé sur une précédente commande ;
- cumul avec une autre promotion en cours.

Le message affiché lors du refus indique le motif. Le support ne peut pas forcer l'application d'un code non éligible.

## 5. Modification du panier après application

Si le client modifie son panier après avoir appliqué un code, la remise est recalculée automatiquement. Si le panier passe sous le minimum requis, le code est retiré.

## 6. Programme de fidélité NovaPoints

- **1 point** gagné par tranche de 10 MAD dépensés.
- **100 points = 20 MAD** de réduction.
- Les points sont crédités **15 jours** après la livraison, pour tenir compte du délai de retour.
- Les points expirent **24 mois** après leur acquisition.
- Les points ne sont pas échangeables contre des espèces.

| Statut | Seuil annuel | Avantage |
| --- | --- | --- |
| Classic | 0 MAD | 1 point / 10 MAD |
| Silver | 5 000 MAD | 1,25 point / 10 MAD |
| Gold | 15 000 MAD | 1,5 point / 10 MAD + livraison offerte |

Les points sont annulés en cas de retour du produit ou de remboursement intégral.

## 7. Prix erroné

En cas d'erreur manifeste de prix (par exemple un article à 10 MAD au lieu de 1 000 MAD), NovaShop peut annuler la commande et rembourser intégralement le client, conformément à POL-08, section 6.

## 8. Cartes cadeaux

Les cartes cadeaux sont valables 12 mois, utilisables en plusieurs fois, non remboursables en espèces et non rechargeables. Elles peuvent être cumulées avec un code promo.

## 9. Litige promotionnel

Toute contestation doit être envoyée dans les **30 jours** suivant la commande, avec une capture d'écran de l'offre. Le support vérifie la campagne concernée et répond sous 5 jours ouvrés.
